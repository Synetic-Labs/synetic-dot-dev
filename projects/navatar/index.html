Project Navatar

High-speed autonomous drone racing

■ About

High-speed autonomous drone racing using state-of-the-art deep reinforcement learning techniques. The machine learning methods used include world models, soft actor-critic and behavioural cloning, to efficiently train the drone in simulation to perform superhuman actions in the real world.
